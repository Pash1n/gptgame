# Сдвиг 0.51 — бригада и смены

Передняя лавка, отдых лицом к грузам, жёлтые/синие каски. Два комплектовщика бесплатно со старта, найм ещё двоих. Цены ×10, доплата за смешанный состав, зарплата после пяти заказов. Шкафчик и оборудование перемещаются при расширении.

[Запуск и управление](README_RU.md) · [Проверки и ограничения](REPORT_0.51_RU.md)

`npm ci`, `npm run build`, `npm test`. Нативные проверки Jolt выполняют физические действия краном без телепортации грузов. Браузер — сервер8163 и Playwright/Chromium. `python tools/package.py` создаёт автономный HTML и архивы до100МБ каждый.
