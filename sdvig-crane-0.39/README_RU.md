# Магнитная мастерская 0.39 — Jolt WASM

Экспериментальная замена физики: столкновения, сон тел, цепь и соединения рассчитывает Jolt Physics.js 1.1.1 через WebAssembly, один поток. Старые модели, PBR-материалы, текстуры, свет, тени, интерфейс, камера и раскладки 120/240/400 сохранены из 0.38. Cannon-es используется только как библиотека векторов, описаний форм и совместимых игровых объектов; Cannon.World не запускается.

Распакуйте ZIP и откройте Sdvig_MAGNETIC_CRANE.html. Интернет не нужен: WASM встроен. По умолчанию 240 деталей. Меню → заказ → Тест завала: 120 / 240 / 400; 400 — стресс-тест. Оба приёмника принимают всё. Тест не записывает добычу или награды. Ключ сохранений прежний. Прежние заказы и тест верстака доступны в меню.

ПК: WASD; Q/E — высота; пробел — магнит. Телефон: первый палец ведёт, второй меняет высоту, кнопка включает магнит. Сверху JOLT, FPS, время физики за кадр и активные тела. Сравнивайте с 0.38 на одном размере, в одной ориентации, с одинаковым качеством графики и во время разгребания. На слабом устройстве начните со 120. На реальном телефоне и аппаратном WebGL эта версия здесь не проверялась.

Сборка: npm ci && npm run build. Jolt входит в vendor/jolt и не требует скачивания при запуске. Упаковка python3 tools/package.py. Замеры/методика в REPORT_0.39_RU.md, сырые результаты reports/engine-comparison.json. Для воспроизведения сравнения рядом нужна сохранённая папка sdvig-crane-0.38. Старые отчёты скопированы из предыдущих версий и не являются новым прогоном.
