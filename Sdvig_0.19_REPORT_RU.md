# Сдвиг 0.19 — ледяная змейка

Выпуск 27 октября 2026 года.

## Что изменено

Девять новых рисованных спрайтов: пять желеек внутри прозрачного льда, светящийся ободок клетки, кометный указатель удерживаемого жеста, треснувший ледяной ободок и эффект оттаивания. Пять составных ледяных персонажей заменяют закрепления. Лёд не дышит и не покачивается вместе с рядом. При освобождении появляется эффект осколков. Исходный атлас сохранён в art-source.

При удерживании выбранного ряда/столбца подсвечиваются все участвующие клетки, включая клетки объезда, а не пунктир между ними. Подсветка работает и на первых 20 авторских уровнях. Кометные указатели показывают направление.

Новый маршрут — настоящая циклическая перестановка. Замороженные клетки исключаются, непрерывные группы льда обходятся вместе. Предпочитается верхний/левый проход либо сторона переключателя, при препятствии пробуется противоположный. Несколько обходов подбираются без повторения клеток; возможны разные стороны в одной змейке. На краю поля сохраняется циклический переход. Все клетки вне маршрута неподвижны. Полностью перекрытый путь не превращается в прыжок сквозь лёд: сдвиг недоступен. Обход ищется в непосредственно соседних рядах/столбцах; произвольный лабиринт через несколько дальних рядов не строится.

Отрисовка интерполирует движение по последовательным клеткам маршрута. Исчезла декоративная дуга прыжка над препятствием. Скорость завершения сдвига учитывает расстояние. Закрепление больше не изображается гвоздём. Совпадения и каскады начинаются только после завершения сдвига.

Учебные уровни 52, 53, 54 показывают нижний проход при двух замороженных по вертикали, длинную группу и несколько обходов. Из-за изменения правил пересчитаны решения 71 уровня, в том числе этих трёх. Начальные поля 196 и 308 пересобраны; остальные прежние поля сохранены. Подробности — snake-repaired-levels.json. Из решений удалены избыточные блоки, но кратчайшие решения не доказаны.

## Сохранения

Прежние ключи localStorage сохранены. Звёзды и открытые уровни не обнуляются. Старый незавершённый уровень с изменившимися правилами перезапускается. Остальные старые поля восстанавливаются, новый снимок имеет revision 19. Проверены оба сценария на старых снимках revision 14.

- В одном из тестов 300 полей с фиксированным seed, 3600 вариантов оси/линии: проверены уникальность клеток, соседство пути, неподвижность льда и посторонних клеток, сохранение всех объектов и точный обратный сдвиг. Это не перебор всех возможных полей.

- Все 500 уровней в Chromium через исходную сборку: 7750 ходов, 0 ошибок — levels-browser.json. Полное сравнение современного состояния с ядром после каждого хода.

## Найденные и исправленные проблемы

Прежние решения 68 уровней перестали выигрывать после замены пропуска закреплений на настоящую змейку. Они пересчитаны, дополнительно обновлены три учебных уровня. Первоначальный поиск не справился с полем 196, затем отдельный поиск подобрал новое поле с теми же целями; второе пересобранное поле — 308.

Прежний ввод допускал отпускание на шесть клеток: для обычного ряда это полный оборот, но для восьмиклеточной змейки движение реально и могло остаться неучтённым. Диапазон ограничен согласованными с ядром пятью шагами, ненулевой завершённый сдвиг учитывается как ход. Отмена нулевого сдвига больше не показывает ложное сообщение о запрете.

Один тест старых сохранений первоначально подменял localStorage в ещё работающей игре и сам затирал фикстуру сохранением при уходе со страницы. Фикстура перенесена в начало загрузки нового документа; проверка миграции после этого прошла. Ошибки переноса заработанных звёзд в самой игре не обнаружено.

## Ограничения

Реальные смартфоны, Safari и Firefox не проверены; FPS на устройствах не измерен. Автономность проверена через HTTP без внешних запросов; file:// ограничен политикой тестового браузера. Произвольный многострочный поиск пути не реализован: используются соседние линии и группировка препятствий. Решаемость подтверждена указанными решениями, не всеми возможными действиями игрока и не оптимальностью. Для изменённых незавершённых уровней поле перезапускается, заработанные результаты сохраняются. Перенос между разными origin браузера не автоматический. Исторические отчёты других выпусков не считаются новой проверкой.
