# Сдвиг · Склад метизов 0.49

30 SKU, сборная закупка, транспортные ящики до 25 коробок, индивидуальные остатки и комплектация клиентских заявок на отдельном упаковочном столе. Можно отправлять 1/25, 12/25 и любой другой нужный неполный ящик. Два стропальщика, физический кран, расширение 4 → 8 мест и поставки 2 → 4 ящика сохранены.

[Запуск, игровой цикл и ограничения](README_RU.md) · [Отчёт](REPORT_0.49_RU.md).

Новый сценарий сохраняется отдельно от 0.48. `npm ci`, `npm run build`, `npm test`. Упаковка — `python tools/package.py`. Приёмочные сценарии — `test-metiz.mjs`, `test-metiz-guards.mjs`, `test-metiz-browser.cjs`, `test-offline.cjs`; исторические проверки старого двухтоварного режима не являются приёмкой нового сценария.
