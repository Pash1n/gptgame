СДВИГ — ЛЁГКИЙ СКЛАД 0.47

Распакуйте игровой архив и откройте Sdvig_WAREHOUSE.html браузером с WebGL2. Ресурсы, физика и изображения встроены, интернет для игры не нужен. Предыдущие версии не изменены.

ГРАФИКА
Реальные источники света, динамические карты теней, SSAO, отражения окружения и постобработка убраны во всех режимах. Рисунок света и теней на полу запечён заранее. Объём остальных моделей задан цветами вершин и статичными текстурами. Под грузом, машиной, крюком и ногами работника — мягкие текстурные тени. Мелкие скругления упрощены, работник отрисовывается девятью группами по материалам с прежней анимацией. Сглаживание MSAA отключено. Неподвижная сцена не перерисовывается заново; физика и часы игры продолжают работать. В покое мелкая анимация дыхания не обновляется, движение и работа анимируются.

По умолчанию Чётче: нативная плотность без увеличения внутреннего разрешения выше DPR 1, бюджет до 1,44 млн пикселей. Режимы Авто и Быстрее меняют разрешение, тяжёлые эффекты не включают. Ручной выбор сохраняется. При необходимости выберите Быстрее в меню.

НАЧАЛО
Пустой склад на четыре места, 2 000 ₽. Нажмите на стол с компьютером или кнопку КОМПЬЮТЕР справа сверху. Откроется рабочий стол с программами Поставщики, Покупатели, Мой склад и закрытые Контракты. Работа крана приостановлена; К крану возвращает в игру.

Закажите один/два поддона, подтвердите сумму и закройте компьютер. Приехавшую машину разгружайте краном на четыре отмеченных места. Затем найдите покупателя на имеющийся товар, подтвердите продажу и погрузите проданные поддоны в подписанную разметку кузова. Оплата после выезда машины. Один поставщик, два товара, одна машина за раз; расширений и контрактов пока нет.

WASD — кран, Q — поднять крюк, E — опустить. Нажмите на поддон, работник приготовит стропы. Опустите крюк к петле — подцепление автоматическое. Пробел или кнопка отцепляет только груз на опоре. В кузове покупателя после отцепления поднимите крюк: работник снимет обвязку, отойдёт и машина примет груз. Одинаковые поддоны можно ставить в любое свободное отмеченное место. Принятый груз остаётся физическим препятствием. Подвеска реагирует на массу груза; колёса остаются на земле.

Телефон: первый палец перемещает кран, второй вверх-вниз регулирует высоту; короткое касание выбирает груз. Отцепление кнопкой. Колесо мыши — приближение; на телефоне зум в меню. Осмотреть кран в меню показывает механизм; WASD возвращает обычный вид. Подсказки — приглушённым текстом в углу без плашек.

Пауза P или меню. После сворачивания нажмите Продолжить. Деньги, товар, сделки, машина, подвеска и груз на крюке сохраняются в том же ключе браузера, что в 0.43–0.46. Открывайте обновлённый HTML тем же браузером и по тому же адресу/пути. Сохранение локальное; если браузер запрещает запись, появится сообщение. Новый бизнес сбрасывает кампанию только после подтверждения.

ИСТОЧНИКИ И ПРОВЕРКИ
npm ci; npm run build; python -m http.server 8158. npm test проверяет торговый цикл, tools/test-truck.mjs — столкновения/подвеску. Для tools/test-lite.cjs и tools/test-offline.cjs нужны Playwright и Chromium. Проверки размеров экрана не заменяют настоящий телефон. Замеры скорости сделаны на программном SwiftShader, FPS на реальном устройстве не обещается.

Свет пола уже запечён в assets/baked-floor.png. Для изменения архитектуры: соберите JS, запустите сервер 8158, выполните npm run bake:floor, затем пересоберите. BVH и PNGjs нужны только для офлайн-запекания; в браузерную сборку не включаются. Для сравнения производительности tools/benchmark-render.cjs нужны также исходная 0.46 на сервере 8157 и 0.47 на 8158. tools/package.py собирает автономный HTML и архивы в SDVIG_OUT.
