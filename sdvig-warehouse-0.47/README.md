# Сдвиг · Лёгкий рендер 0.47

Запечённый свет пола, простые текстурные материалы с цветами вершин, текстурные мягкие тени. Без SSAO, динамических теней, источников света и HDR-отражений. Упрощена геометрия, сгруппирована анимация работника, неподвижная сцена не перерисовывается. Физика и торговля сохранены.

[Запуск, ограничения и проверки](README_RU.md). npm run bake:floor — повторное офлайн-запекание после изменения архитектуры.
