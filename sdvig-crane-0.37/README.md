# Магнитная мастерская 0.37 — глава 1: электростанция

Пять уровней добычи → пять сборок узлов → общая сборка и запуск электростанции. Это законченная первая глава будущей игры о восстановлении города; остальные городские объекты пока не реализованы.

## Запуск

Распакуйте игровой ZIP и откройте `Sdvig_MAGNETIC_CRANE.html` браузером с WebGL. Интернет и установка не нужны. Для исходной версии достаточно `python3 -m http.server 8146` в этой папке и http://localhost:8146 .

## Первая глава

1. **Редуктор** — корпус, два вала, две латунные шестерни, крышка; 24 физических предмета на уровне.
2. **Двигатель** — блок цилиндров, коленвал, два поршня, маховик, головка; 27 предметов.
3. **Генератор** — станина, две обмотки, ротор и щит; 29 предметов, перегородка с проходом и обрезки кабеля среди целей.
4. **Охлаждение** — радиатор, насос, два патрубка, вентилятор и бачок; 33 предмета, стойки и хрупкий радиатор.
5. **Пульт** — корпус, две платы, два прибора, рубильник и жгут; 37 предметов, четыре хрупкие детали.
6. **Общая сборка** — пять готовых агрегатов, муфты силового привода, шланги и питание, затем четыре крепления общей рамы. После запуска станция появляется на подготовленной площадке мастерской, механизмы движутся и включается свет.

Следующий уровень открывается после сборки предыдущего узла. Доставленные детали, установленные части, отдельные затянутые болты и запуск станции сохраняются.

## Куда нести груз

**Справа голубой приёмник «ДЕТАЛИ УЗЛА»** с названием текущего узла и объёмным образцом. **Слева оранжевый «ЛОМ»** для лишнего металла. Поднятый груз подсвечивает соответствующий приёмник. Нужные латунные шестерни отличаются от обычных стальных.

Приёмник проверяет всю партию после сброса. Если внутри есть лишняя деталь, ни одна правильная не исчезает и не засчитывается. Подсвеченный предмет и подпись «Убери: …» показывают причину. Вытащите лишнее полностью выше борта — правильные детали примутся после короткой проверки. Две нужные детали принимаются вместе; лишний экземпляр сверх оставшегося задания блокирует партию. Нужную деталь нельзя случайно удалить в лом: она блокирует и левый приёмник, пока её не вынести.

В новых уровнях весь мусор можно притянуть магнитом. Если предмет застрял вне досягаемости на внешнем краю или перегородке, после короткого покоя игра вернёт его на площадку. Предметы внутри приёмников из этого возврата исключены.

## Управление

ПК: WASD — перемещение крана, Q/E — поднять/опустить, пробел — магнит, P — пауза. Телефон: первый палец перемещает, второй меняет высоту; большая кнопка включает магнит. Восемь верхних ламп при включении горят красным. После сворачивания нажмите «Продолжить».

На верстаке перетаскивайте детали мышью или одним пальцем в объёмное подсвеченное место. Затем удерживайте каждый подсвеченный болт около секунды. Механизм можно запустить и остановить; крышку редуктора открыть. Повторная сборка готового узла сохраняет ранее полученные открытия.

**Сразу посмотреть все сборки:** меню → «Тест верстака · детали выданы», затем выбирайте узел верхней/боковой полосой. Тест использует временный инвентарь и не пишет основной прогресс. В меню есть отдельный доступ ко всем уровням. Прежние десять глав перевозчика, три заказа и свободная свалка сохранены.

## Сохранения и разработка

Используется прежний `sdvig-crane-v1`. Данные редуктора 0.36 переносятся в `stationModules.gearbox`, старые заказы и история сохраняются. Точная куча предметов не сохраняется. LocalStorage зависит от браузера и адреса/пути файла; перенос файла не гарантирует перенос сохранения.

```sh
npm ci
npm run build
node tools/test-receiver-policy.mjs
node tools/test-fragile-contact.mjs
node tools/test-station-state.mjs
node tools/test-chapter-physics.mjs
node tools/test-chapter-browser.cjs
node tools/test-station-browser.cjs
node tools/test-receivers-browser.cjs
node tools/test-station-viewports.cjs
python3 tools/package.py
node tools/test-offline37.cjs
```

Браузерным инструментам нужны Playwright, Chromium (`/usr/bin/chromium`), сервер исходников на 8146 и сервер упакованного HTML на 8137. Старые инструменты 0.35/0.36 включены для справки; их адреса и ожидания могут относиться к прежним версиям. Выполненные проверки и ограничения перечислены в `REPORT_RU.md`, журналы лежат в `reports/`.
