# Склад 2.5D — проба 0.2

Новая отдельная проба: рисованная картинка, наклонный фиксированный вид, два ряда (6 мест), объёмные столкновения и раскачивание по двум горизонтальным осям. Три физических груза: поддон на подвесе и два ящика на полу. Можно переставлять между рядами и ставить друг на друга. Фон и предметы — PNG-спрайты, Canvas 2D, без WebGL, освещения и расчёта теней. Предыдущие версии и сохранения не меняются.

## Запуск и управление

Распакуйте ZIP и откройте Sdvig_SPRITE_25D.html. Все ресурсы внутри, интернет не нужен. На ПК WASD — перемещение тележки и моста, Q/E — подъём/спуск, пробел — сцепить/отцепить ближайший груз, R — заново, P — пауза. Щелчки мышью не перемещают кран.

На телефоне один палец перемещает кран по площадке, второй палец вверх/вниз поднимает/опускает крюк. Добавление второго пальца само по себе не выдаёт команду. Кнопка сцепки работает при удерживаемом первом пальце. При отпускании первого второй становится основным без скачка. После сворачивания — кнопка «Продолжить». Для обзора двух рядов удобнее горизонтальная ориентация.

## Что изменено в физике

Вместо плоской физики Matter.js используется Cannon-es 0.20.0 (MIT), три измерения, метры/килограммы/секунды, шаг 1/120 с, гравитация 9.81 м/с². Массы: крюк 45 кг, поддон 420 кг, ящики 680 кг. Рисунки всегда повёрнуты одной стороной, угловое вращение физических тел заблокировано по договорённости. Поэтому ящик не переворачивается через край при потере опоры.

Трос и стропы — два односторонних физических соединения: только растяжение, без выталкивания вниз ослабленным подвесом. Плавное ускорение загруженного крана 1 м/с², скорость до 1.55 м/с по каждой горизонтальной оси, подъём до 0.7 м/с с ограничением разгона. В подвесе есть игровое демпфирование, нулевой коэффициент отскока на контактах. Массы сами по себе не замедляют свободное падение. За ощущение тяжести отвечают масштаб, ускорения, контакт и затухание.

Проекция ортографическая: дальний груз не уменьшается, ближний корректно перекрывает дальний. Верхний груз отображается выше нижнего. Площадка имеет запас глубины для третьего ряда; в пробе размечены только два, переключателя расширения пока нет.

## Проверка и ограничения

Автоматические проверки reports/physics.json и reports/browser.json: покой подвеса, ограничение разгона, раскачка, затухание, падение, фиксированная ориентация, укладка на ящик, опускание с ослаблением троса; клавиатура, настоящие двухпальцевые события Chromium, сцепка при удерживаемом пальце, продолжение после паузы, горизонтальный и вертикальный экран. Часть отдельных физических проверок использует явно заданное начальное положение груза; браузерная укладка выполняется обычным движением крана.

Это проба ощущений, не законченная игра: нет заказов, рабочего, машины, экономики, сохранения и звука. Автоматическая сцепка поблизости без ручного стропования. Стропы нарисованы линиями, работают через одно физическое соединение с верхом груза; точная симуляция четырёх строп и разрывов не заявляется. Нет свободного вращения и точной формы каждой доски. Графика подготовлена для фиксированного ракурса, не для вращения камеры. Простая сортировка спрайтов может иметь ограничения при сложных частичных перекрытиях. Скорость на реальных телефонах ещё не измерялась. Canvas под разрешение экрана с DPR до 2; фон имеет конечное исходное разрешение 1672×941.

## Исходники

src/physics.js — объёмная физика; src/main.js — проекция и управление; src/touch-controls.js — стабильные роли пальцев; assets/ — рисунки, vendor/ — Cannon-es и MIT-лицензия. Для пересборки установите Node.js, выполните npm install и npm run build. Полная упаковка: python tools/package.py. Физическая проверка: npm test. Браузерная: tools/test-browser.cjs (Playwright, Chromium, HTTP-сервер репозитория на порту 8160). Зависимости браузеру не нужны.

Дополнительно проверены повторная сцепка и подъём после обычной укладки, отсутствие «невидимой опоры» от ящика в другом ряду и контакт крюка с собственным грузом при ослабленном подвесе. Standalone HTML проверен с отключённой сетью, с единственным HTML, поданным из памяти; прямой запуск file:// в автоматизации не проверялся из-за политики Chromium среды. В пробе canvas 1920×1080 действительно имеет 1920×1080 пикселей; на телефоне 390×844 с DPR 2 — 780×1688.
