# Сдвиг · Магнитная мастерская 0.33

Исправления управления, паузы, мерцания приёмников и стабильности кадров после возврата. Версии 0.31 и 0.32 сохранены отдельно. Три заказа и свободный режим доступны всем.

## Запуск
Распакуйте ZIP и откройте **Sdvig_MAGNETIC_CRANE.html** обычным браузером с WebGL. Код, модели и изображения встроены; интернет для игры не нужен. Для исходников: `python3 -m http.server 8139`, затем http://localhost:8139 .

## Управление
**ПК:** WASD — перемещать магнит; **Q — поднять, E — опустить; пробел — включить/выключить**. Физические коды клавиш работают и с русской раскладкой. P — пауза/продолжение. Клик и перетаскивание мышью больше не двигают кран; колесо тоже не меняет высоту.

**Телефон:** первый палец двигает магнит, второй вверх-вниз меняет высоту. Кнопку магнита можно нажимать другим пальцем, не отпуская площадку. Убирая пальцы, груз не сбрасываете; для сброса нажмите кнопку. Если убрать первый палец, оставшийся продолжит перемещение без скачка.

После сворачивания игра ждёт на паузе. Нажмите большую кнопку **«Продолжить»** прямо на поле. Меню для этого не нужно. При уходе со страницы из меню оно закрывается, чтобы кнопка продолжения оставалась доступна.

## Цель
Голубой приёмник справа принимает роботов и шестерни, оранжевый слева — болты, трубы и мотор. Резина не притягивается. Предел магнита — 12 кг. Отпущенный груз засчитывается внутри нужного приёмника после остановки. Неправильный груз можно извлечь обратно. В меню есть общий вид и выбор заказа. Крупная камера следует за магнитом, поэтому часть площадки может быть за кадром.

## Производительность
Сохранён облегчённый рендер 0.32: без SSAO, объединённые PCF-тени 30 раз/с (быстрый режим — 20), умеренная геометрия, ограничение пикселей. Графика в меню переключается: авто → чётче → быстрее. Авто начинает с лимита около 1,1 млн пикселей и плотности 1; при устойчивых медленных кадрах разрешение уменьшается до 55% начального масштаба. Во время игры оно больше не повышается автоматически: это исключает повторные циклы повышения нагрузки и перестройки буферов. Выбор «Авто» заново или перезапуск возвращает начальный масштаб.

Новый отсчёт кадров сохраняет частоту при дрожании временных меток: контрольная последовательность дала 599 из 600 кадров, старый ограничитель — 300. Это синтетический тест планировщика, не аппаратный FPS. На 60/120/144 Гц тестовый планировщик выдаёт около 60 кадров/с.

При паузе и скрытии RAF отменяется. При продолжении сбрасываются интервалы, очередь физики и замеры адаптации; выбранное облегчённое разрешение сохраняется. Неизменившийся размер окна не вызывает повторную установку размера canvas. Проверены отсутствие роста текстур/геометрии/шейдеров после повторных возвратов, единственный цикл и восстановление после реальной потери WebGL-контекста.

Физика считает прежние шаги 1/120 с; в очень медленном кадре допускается не более пяти шагов. При сильных тормозах симуляция замедляется, вместо догоняющего рывка. GPU-геометрия/материал искр теперь общие, не создаются заново после каждого захвата.

## Проверки
`npm ci`, `npm run build`. Готовый game.js включён, для игры установка зависимостей не нужна.

- `node tools/test-frame-clock.mjs` — частоты, дрожание интервалов, остановки и сброс таймера.
- `node tools/test-touch.mjs`, `node tools/test-physics.mjs`, `node tools/test-natural.mjs` — жесты, физика и три заказа без телепортации груза.
- `node tools/test-browser.cjs` — клавиатура, неактивная мышь, меню, все три заказа, пять размеров экрана и двухпальцевые CDP-события.
- `node tools/test-input-regressions.cjs` — кнопка вторым пальцем, повтор/фокус пробела, русская раскладка и выделение.
- `node tools/test-lifecycle.cjs` — повторные остановки/продолжения, ресурсы, RAF и WebGL restore.
- `node tools/test-performance.cjs` — бюджет рендера, адаптация, 4K и старые сохранения.
- `python3 tools/package.py` — автономный HTML и ZIP в SDVIG_OUT или /workspace/artifacts.
- `node tools/test-offline.cjs` — автономный HTML через HTTP 8137, затем отключение сети.

Средства автоматизации доступны только с `?test=1`; игроку они не нужны. Отчёты в reports/, список замечаний и исправлений в CHANGELOG_RU.md. Сохранён ключ sdvig-crane-v1 и отметки заказов; сохранения поезда не меняются. Точное положение кучи не сохраняется.

## Ограничения
Управляемый Chromium не переключает видимость headless-вкладок как обычный браузер: обработчики blur/hidden/freeze проверены явно отправленными событиями. Это не полное воспроизведение переключения вкладок на ПК пользователя. Потеря и восстановление графического контекста проверены настоящим WEBGL_lose_context. Реальные телефоны, Safari и аппаратный FPS не проверены. file:// запрещён политикой тестового браузера, автономность проверена через локальный HTTP с последующим отключением сети.

Это прототип с тремя заказами, без большой кампании и звука. Магнитное поле игровое, коллайдеры приближённые, роботы твёрдые, не ragdoll. Цепь связана ограничениями без столкновений её звеньев; дальнее окружение нарисовано, находки и площадка настоящие 3D.
