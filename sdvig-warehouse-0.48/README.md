# Сдвиг · Складской бизнес 0.48

Развитие полноценного склада 0.47: предложения покупателей и смешанные заказы, соседний пролёт (4 → 8 мест), транспорт (2 → 4 поддона), повторяемые комплектные контракты, доставка в себестоимости и вращение колёс.

Лёгкий рендер 0.47 сохранён: без источников света, PBR, SSAO и динамических карт теней. Предыдущие проекты и ключ старого сохранения не меняются.

[Запуск, цены, управление и ограничения](README_RU.md) · [Фактический отчёт о проверках](REPORT_0.48_RU.md).

`npm ci`, `npm run build`, `python -m http.server 8159`. `npm test` проверяет путь до расширения, четырёхпалетных поставок и завершённого контракта обычными игровыми действиями. `python tools/package.py` создаёт standalone HTML, ZIP и исходники.
