СДВИГ — СКЛАДСКОЙ БИЗНЕС 0.48

Распакуйте архив, откройте Sdvig_WAREHOUSE.html в современном браузере с WebGL2. Интернет после распаковки не нужен. Основа — версия 0.47 с лёгким рендером: текстуры и заранее подготовленный свет, без динамического освещения, SSAO и карт теней.

ЧТО ДЕЛАТЬ
Начало: 2 000 ₽, четыре места, поставки по одному или два поддона. Откройте компьютер на столе или кнопкой сверху. В «Покупателях» смотрите нужные товары, закупайте их у поставщика, разгружайте на размеченные места. После приёма товара на склад можно принять предложение покупателя и собрать отгрузку.

Три обычных предложения включают небольшой заказ, партию из двух поддонов и смешанный комплект «двигатели + запчасти». Закупки не меняют предложения — сначала можно собрать нужные товары. Новый выпуск приходит после завершения продажи. Быстрый выкуп остаётся запасным выходом, но его цена ниже и маленькая закупка с доставкой может оказаться убыточной при таком выкупе.

ПЕРВАЯ ЦЕЛЬ
После двух завершённых продаж в «Развитии» можно купить соседний пролёт за 1 200 ₽. Вместимость вырастет с четырёх до восьми мест. Откроются четыре площадки слева, проезд крана и подход стропальщика. Расширение видно и работает физически, не только меняет цифру в меню.

После трёх продаж и расширения доступен транспорт до четырёх поддонов за 650 ₽. Затем можно заказывать 1, 2, 3 или 4, а у покупателей появятся крупные и смешанные партии из четырёх. Кузов имеет отдельную раскладку из четырёх мест. Для любой покупки улучшения должно остаться минимум 360 ₽ на следующую закупку.

После расширения «Контракты» предлагают две последовательные комплектные отгрузки: по одному поддону двигателей и запчастей в каждой. Каждая оплачивается по 1 500 ₽, после второй дополнительно 250 ₽. Прогресс и выплаченный бонус сохраняются. Пока нет таймеров, штрафов и аренды.

ДЕНЬГИ И ДОСТАВКА
Двигатели: 650 ₽ за поддон, запчасти: 320 ₽. Доставка 1–2 поддонов — 40 ₽ за машину; 3–4 — 70 ₽. Полная цена показывается до подтверждения. Доставка включается в себестоимость товара. Оплата покупателя приходит после погрузки и выезда, один раз. «Прибыль» — операционная прибыль от продаж и контрактных бонусов; покупка площади и транспорта отдельно уменьшает денежный счёт как инвестиция.

УПРАВЛЕНИЕ
WASD — перемещение крана, Q/E — поднять/опустить, пробел — отцепить установленный груз, P — пауза. Щелчок по поддону вызывает стропальщика; кран мышью не телепортируется. При погрузке отцепите груз и поднимите крюк, работник снимет стропы и отойдёт. Кнопка «Снять стропы» позволяет сделать это вручную.
Телефон: один палец перемещает кран по площадке, второй вверх/вниз управляет высотой. Короткое касание товара вызывает стропальщика. Кнопки внизу. После сворачивания — «Продолжить». Колёса машины вращаются при движении и стоят при остановке, подвеска и столкновения кузова сохранены.

СОХРАНЕНИЕ
Новый ключ: sdvig-warehouse-business-v2. Если его нет, игра пробует прочитать прежний sdvig-warehouse-business-v1 и переносит его без изменения старого ключа. Прежние деньги, грузы, принятые сделки и себестоимость не пересчитываются задним числом. Старый HTML 0.47 и его сохранение остаются отдельно.
Локальные сохранения зависят от браузера и адреса. При открытии HTML из другого файла браузер может выделить ему отдельное хранилище; перенос между устройствами/путями не гарантируется. Новый бизнес сбрасывается только через существующее подтверждение в меню.

ПРОВЕРКИ
npm test / tools/test-progression.mjs — полный цикл обычными командами: две продажи, расширение, смешанный заказ, транспорт, разгрузка и погрузка четырёх поддонов, повторная загрузка сохранения посреди погрузки, обе части контракта и однократный бонус. Без выдачи денег и телепортации товара.
tools/test-business-guards.mjs — перенос настоящего сохранения 0.47, проверки ограничений и сохранений, отдельная поставка трёх поддонов. Нужен соседний исходник 0.47 для проверки миграции.
tools/test-truck.mjs — отдельные явно заданные физические сценарии столкновений/подвески, не обычное прохождение.
tools/test-business-browser.cjs — компьютер, предложения, улучшения, реальные колёса, четыре поддона, восемь мест, размеры экрана, миграция хранилища, пауза. Состояние расширенного склада взято из естественно заработанного сохранения полного теста.
tools/test-offline.cjs — автономный HTML после отключения сети. Прямой file:// в автоматизации не проверен. Размеры телефона эмулированы, проверка на настоящем телефоне ещё нужна.

ОГРАНИЧЕНИЯ
Это первая ступень экономики: два товара, один действующий поставщик, одна машина за раз, расширение до восьми мест и партии до четырёх. Фуры на 6–8 поддонов, вторые ворота, новые товары, аренда, рынок с конкуренцией и дальнейшие площади пока не добавлены. Обычные предложения детерминированно меняются по циклу, полноценного биржевого рынка нет. Нет отдельной системы банкротства/кредитов; не стоит расходовать остаток через убыточный быстрый выкуп.
Аннекс использует те же статичные материалы; прежняя карта запечённого света сохранена для старого зала, в новом нет пересчёта теней в реальном времени. Груз на обвязке мягко стабилизируется по вращению физическим моментом, чтобы не разворачивался поперёк четырёхместного кузова. Столкновения по-прежнему объёмные.

ИСХОДНИКИ
Node.js, npm ci, npm run build; python -m http.server 8159. Упаковка: python tools/package.py, выход /workspace/artifacts или SDVIG_OUT. Браузерные тесты требуют Playwright и Chromium. vendor содержит Jolt WASM; используется один поток. Размер каждой итоговой сборки меньше 100 МБ.
