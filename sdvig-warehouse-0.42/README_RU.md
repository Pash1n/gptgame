СДВИГ — МАЛЕНЬКИЙ СКЛАД 0.42

Распакуйте игровой архив и откройте Sdvig_WAREHOUSE.html в современном браузере с WebGL2. Интернет для ресурсов игры не нужен: изображения и Jolt WASM встроены в HTML.

Это отдельная визуальная версия склада на четыре места. Экономика, поставщик, закупка, деньги и расширения ещё не реализованы. Пока доступны два пробных заказа: два поддона двигателей, затем два поддона запчастей. Старые версии и их сохранения не изменяются. Текущая смена после закрытия не сохраняется.

WASD — перемещать кран; Q — поднять крюк; E — опустить; пробел — отцепить груз на опоре. Щёлкните по поддону: работник подготовит обвязку, затем опустите крюк к петле. Подцепление автоматическое.

Справа площадка ПЕРЕДАЧА. Поставьте туда нужный поддон, отцепите крюк и поднимите его. Работник снимет обвязку, погрузчик отвезёт груз в машину.

Телефон: первый палец перемещает кран, второй вверх-вниз регулирует высоту; короткое касание выбирает поддон. Отцепление кнопкой.

Колесо мыши приближает/отдаляет камеру. На телефоне кнопки приближения есть в меню. В меню также общий вид, качество и новая смена. Пауза P или меню; после сворачивания нажмите Продолжить.

Режим «быстрее» отключает экранное затенение SSAO и уменьшает разрешение теней. Авто и чётче используют SSAO в половинном разрешении. Проверка на реальном телефоне и оценка аппаратного FPS не проводились.

Для тестового API добавьте ?test=1 к адресу сервера. Все четыре места доступны сразу; дополнительных уровней и блокировок нет.

Исходники: npm ci, npm run build; python -m http.server 8153. npm test проверяет полный цикл отправки четырёх поддонов. tools/test-browser.cjs проверяет управление и делает скриншоты (нужны Playwright и Chromium). tools/package.py собирает автономный HTML и архивы в SDVIG_OUT (по умолчанию /workspace/artifacts).
