# Сдвиг 0.14 — Желейные тропы

Новая версия проекта; 0.13 и исходный архив 0.12 сохранены отдельно. Все 500 уровней открыты в автономной тестовой сборке.

## Изменения

Реализованы три новых правила: реальный объезд штифта через три клетки соседнего ряда/столбца, порталы с обменом желеек при затрагивании одного входа и переключатель стороны объезда. Это детерминированные правила общего движка, поддержанные подсказками, отменой, восстановлением и проверками. Для них переработано **113 уровней**. Первые уроки: 51 (5 действий), 131 (2), 151 (5). После них правила усложняются и появляются в поздних комбинациях. Уровни 251–500 сохраняют обязательные 5–9 маяков.

Карта оформлена шестью новыми рисованными спрайтами: островок, кристаллы, грибной домик, сундук, портал, указатель. В каждой главе 50 интерактивных узлов и 25 декоративных сцен. На дороге отмечены уроки и испытания, светлячки анимированы, декорации мягко покачиваются. Сундуки — иллюстрация испытаний, не отдельная система наград.

Желейки дышат, покачиваются, слегка поворачиваются, растягиваются по скорости/направлению перетаскивания, сжимаются поперёк и пружинят при остановке. Направление деформации меняется в поворотах объезда. Декоративная деформация отключается в reduced-motion. Порталы имеют подсветку, световую дугу и встречные частицы.

## Реально проверено

- Общий расчёт: **480/480** процедурных уровней 21–500, **7630 действий**.
- Браузерный движок Chromium 154.0.8037.57: **500/500**, **7679 действий**, ошибок JavaScript/HTTP — **0**.
- Отдельный автономный HTML: **500/500**, **7679 действий**, ошибок JavaScript/HTTP — **0**.
- Для 21–500 после каждого действия сравнивались все клетки, бомбы, штифты, стекло, цели, замки, маяки, печати, RNG, действия, приливы, сторона маршрута, число объездов, переходов и переключений.
- **19/19** модульных тестов. Новые проверки задают точные восьмиклеточные пути по обеим осям, перенос соседних желеек, обратимость перестановки, неподвижность штифта, отказ блокированного пути, переключение стороны и условия активации порталов. Входные состояния не мутируют.
- **18** проверок нового автономного интерфейса: быстрые кнопки, проигрывание трёх новых уроков в реальном времени, отмена и перезагрузка после первого действия каждого урока, отмена настоящего сенсорного перетаскивания, пять размеров экрана, миграция 0.13, отсутствие внешних запросов. Этот прогон повторён после добавления световой дуги портала.
- **18** регрессионных проверок управления: мышь, клавиатура, touch, пауза, отмена, сохранения, некорректный JSON, миграция 0.12, доступ к 500, reduced-motion и открытие замка.
- Карта проверена в 320×568, 390×844, 844×390, 768×1024, 1440×1000: горизонтального переполнения нет. В короткой вертикальной ориентации страница игры может прокручиваться.
- В standalone HTML графика, SVG карты, CSS и скрипты встроены. Проверка переходов между новыми уроками и картой не потребовала ни одного HTTP-запроса за ресурсами: только загрузки самого HTML и его перезагрузок.

Полные прогоны используют API песочницы и детерминированное продвижение времени анимации, а не 500 ручных жестовых прохождений. Отдельные уроки дополнительно проиграны с реальным временем и настоящими событиями ввода. Длины сохранённых решений — верхние границы, кратчайшие пути не доказаны.

## Совместимость и ограничения

- В том же origin звёзды и выбранный уровень переносятся из 0.13; изменённые процедурные поля перезапускаются. Старые сохранения не перезаписываются. История отмены не переносится между сеансами.
- Для прежних штифтов без нового правила сохранены старые перестановки, улучшена только дуговая анимация. Восьмиклеточный маршрут включён на уровнях «Объезд»/«Развилка».
- Новые уровни используют один внутренний штифт. Непроходимые маршруты и пересекающиеся пути связанных линий блокируются, а не проходят через другие крепления.
- Прилив не запускает обмен порталов. Выбранный ряд должен задеть ровно один вход. Сборка на переключателе срабатывает при каждой очистке этой клетки, в том числе несколько раз за каскад.
- Все цели по-прежнему обязательны. Если снять последний штифт до выполнения задания объезда, потребуется отмена или перезапуск.
- Человеческий плейтест баланса и субъективной увлекательности пока не выполнен. Нет полного перебора всех достижимых состояний или гарантии победы после любого ошибочного действия.
- Проверен Chromium, мобильный ввод эмулирован. Физические устройства, Safari, Firefox и фактический FPS на телефонах не проверены.
- Политика облачного Chromium блокирует `file://`; прямой запуск локального файла в этой среде не проверен. Сама игра не использует сетевых зависимостей, проверка выполнена через HTTP.
- Данные localStorage привязаны к origin; при смене домена, порта или правил локальных файлов миграция может быть недоступна. Облачной синхронизации сохранений нет.
- Игровые иллюстрированные фоны сохранены из проекта. Новый спрайтовый атлас и его извлечённые WebP включены в исходники; источник PNG находится в `art-source/`.
