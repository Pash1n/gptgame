# Магнитная мастерская 0.38 — большой завал

Распакуйте игровой ZIP и откройте Sdvig_MAGNETIC_CRANE.html. По умолчанию: 240 физических деталей 29 видов. Меню → заказ → «Тест завала»: 120 / 240 / 400. Все доступны сразу. 400 — стресс-тест.

ПК: WASD, Q вверх, E вниз, пробел — магнит. Телефон: первый палец ведёт, второй меняет высоту; кнопка включает магнит. Оба приёмника убирают любой груз. Показатели производительности сверху; при тормозах меню → Графика: быстрее. Цель этой версии — проверить удовольствие от разгребания и нагрузку. Насадок, выдачи деталей в узлы и сохранения раскладки пока нет. Основной прогресс сохранён; прежние заказы доступны в меню.

Подробности и честные замеры: REPORT_0.38_RU.md. Сборка npm run build; упаковка python3 tools/package.py. Генератор начальной кучки tools/bake-pile.mjs выполняется отдельно, в игре ждать осаждения сотен предметов не нужно.
