# Склад 2.5D — проба 0.3

Исправлены две вещи относительно 0.2: вид спереди и немного сверху с горизонтальной балкой (без диагонального разворота склада) и отзывчивость крана. Рисованный стиль сохранён. Два ряда, 6 мест; три объёмных физических груза. Предыдущие версии не изменены.

## Запуск

Распакуйте ZIP, откройте Sdvig_SPRITE_25D.html в браузере. Все изображения и код внутри, интернет не нужен. На ПК WASD — движение по площадке, Q/E — подъём/спуск, пробел — сцепка, R — заново, P — пауза. Щелчок мыши не перемещает кран.

На телефоне первый палец перемещает кран по площадке, второй вверх/вниз управляет высотой. Роли пальцев стабильны, смена основного пальца не выдаёт скачок команды. Кнопка сцепки работает при удержании другого пальца на сцене. После сворачивания — «Продолжить». Горизонтальная ориентация лучше подходит для обзора склада.

## Ракурс и управление

Фронтальная приподнятая проекция, без поворота камеры по горизонтали. Балка остаётся горизонтальной при движении по глубине. Слабое изменение масштаба с глубиной делает ближний ряд немного крупнее дальнего; пути крана сходятся к дальней стороне. Для правильного совмещения перерисованы фон и спрайты грузов под фронтальный ракурс, стиль сохранён. На полу есть место для третьего ряда; пока размечены только два.

Убраны медленный разгон до 1 м/с² и долгий догоняющий ход. Кран следует команде с коротким фильтром 35 мс и ограничением скорости 4.2 м/с; лебёдка — фильтр 45 мс, до 1.5 м/с. При большом резком жесте кран перемещается с ограниченной скоростью, не телепортируется. Это игровое управление, не симулятор реального разгона многотонного моста. Груз не привязан к пальцу: он остаётся на физическом подвесе, отстаёт и раскачивается.

Сравнение при скачке цели на 0.4 м: в симуляции 120 Гц кран проходит 90% пути за 108 мс вместо 1008 мс в 0.2. Это время реакции модели управления, не замер полной задержки экрана конкретного телефона. Для фактического браузерного жеста отдельно проверено приближение к цели через 150 мс. Числа и условия — reports/response.json и reports/browser.json.

## Физика и графика

Cannon-es 0.20.0, метры/килограммы/секунды, гравитация 9.81 м/с², фиксированный шаг 1/120 с. Крюк 45 кг, поддон 420 кг, ящики 680 кг. Односторонние трос и подвес тянут и могут ослабнуть, но не толкают вниз. Столкновения с полом, ящиками и крюком; можно поставить груз на другой груз и повторно поднять. Демпфирование и отсутствие упругого отскока. По договорённости грузы и крюк не вращаются, остаются одной стороной.

Canvas 2D и PNG-спрайты. Расчёта освещения, динамических теней, WebGL и постобработки нет. Чёткость canvas под экран, DPR до 2; текстуры имеют конечное разрешение, фон 1672×941. Новый фон и предметы нарисованы image_gen; балки, тележка и крюк из предыдущей пробы. Это работающая сцена, не неподвижный концепт.

## Проверки и ограничения

reports/physics.json: покой подвеса, быстрый перенос и затухание раскачки, падение, укладка, ослабление троса без продавливания, повторная сцепка и подъём, отсутствие невидимой опоры от другого ряда. Часть изолированных физических проверок использует заданные начальные положения; браузерная укладка выполняется обычными командами крана.

reports/browser.json: клавиатура, реальные двухпальцевые события Chromium, отклик на небольшой жест, сцепка при удержании пальца, пауза/продолжение, размеры экрана 1600×900, 844×390 и 390×844 с DPR 2. reports/offline.json: самостоятельный HTML при отключённой сети, клавиатура, пауза, 1920×1080. Прямой file:// в автоматизации не проверен из-за политики Chromium среды; в тесте единственный HTML подаётся из памяти. Проверка на настоящем телефоне пользователя ещё нужна.

Это отдельная проба управления и вида, без торговли, машины, рабочего, сохранений и звука. Сцепка автоматическая рядом с верхом груза. Четыре нарисованные ветви строп работают через одно физическое соединение, без моделирования каждой нити. Тела — простые коробки без вращения; при потере опоры они не переворачиваются. При больших жестах раскачка заметнее, чем в медленной пробе. Сортировка спрайтов упрощённая, сложные частичные перекрытия не гарантированы. Старые бизнес-сохранения не используются и не меняются.

## Исходники

src/physics.js — физика; src/projection.js — фронтальный ракурс и обратное преобразование жеста; src/main.js — отрисовка и ввод; src/touch-controls.js — роли пальцев. assets/ — изображения; vendor/ — Cannon-es с MIT-лицензией.

Пересборка: Node.js, npm install, npm run build; упаковка — python tools/package.py. Физические проверки — npm test. tools/test-response.mjs проверяет отклик и проекцию; для сравнения со старой пробой нужен соседний каталог 0.2, без него проверяется новая. Браузерные проверки требуют Playwright, /usr/bin/chromium и сервер всего репозитория на порту 8160. Готовая игра зависимостей не требует.
