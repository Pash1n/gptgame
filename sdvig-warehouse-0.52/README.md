# Сдвиг 0.52 — три активные заявки

Отдельные резервы, составы и ящики для трёх клиентов. Принимать можно до закупки; недостающее считается с учётом чужого резерва. Переключение сборки, возврат неполных ящиков, отгрузка одной заявки во время комплектации другой. Один стол и одна машина.

[Запуск](README_RU.md) · [Проверки и ограничения](REPORT_0.52_RU.md)

npm ci; npm run build; npm test. Браузер — сервер 8164 и tools/test-multi-browser.cjs. python tools/package.py создаёт автономный HTML и архивы до 100 МБ каждый. Старые скрипты оставлены для истории, актуальны multi-orders/multi-guards.
