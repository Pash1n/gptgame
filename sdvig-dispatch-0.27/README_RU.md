# Сдвиг · Магнитный диспетчер 0.27

25 открытых участков: прежние 1–5 и двадцать новых 6–25. Поезд едет самостоятельно; игрок заранее программирует развилки, магниты и сцепки. Рисованная ржавая мастерская, поле 2.5D, анимации остановки, разгрузки, стоянки и подбора.

## Запуск
Распакуйте ZIP и откройте **Sdvig_DISPATCH.html** браузером. Все изображения, код и оформление встроены в файл, подключения к сети для самой игры нет. Исходники: `python -m http.server 8127`, затем http://localhost:8127 .

## Прогрессия
- 1–5: запуск, первая развилка, хвостовой порядок, помощник для ворот и новая погрузка.
- 6–10: две развилки, разные выходы и нижняя перемычка. С 9-го участка появляется ограниченный запас хода.
- 11–15: погрузка с разных складов, два последовательных подбора, сборка состава из одиночного буксира.
- 16–20: помощник для моста, смена выходов после подбора, обмен на складе, два держателя и две стоянки.
- 21–25: большое депо, два шлагбаума, заказ по номерам и повторное использование платформы B.

Длина рейса — не единственный показатель сложности: на новых правилах сначала даётся простой учебный пример, затем несколько операций связываются в один план. Все 25 участков доступны сразу; лента номеров прокручивается отдельно. «План-пример» выставляет проверенное решение. Можно использовать его для просмотра механики, затем очистить и решить самостоятельно.

## Правила
Вагоны повторяют путь буксира. На станции разгружается только **последний вагон** подходящего цвета. Магнит оставляет хвост на боковой платформе, сцепка подбирает заданный рядом вагон в хвост. Только что оставленный вагон не возвращается в ту же секунду. Буксир без вагонов тоже умеет подбирать груз.

Любой цвет вагона на платформе открывает связанные с ней ворота. Каждому шлагбауму соответствует своя буква, кабель и отдельная карточка состояния. После подбора держателя эти ворота закрываются.

Развилка меняет ветку после прохода всего состава, если включено чередование. Две развилки могут чередоваться независимо. Подсветка показывает **следующие восемь шагов** текущего плана, а не весь рейс.

**Запас хода** расходуется по одной единице за клетку, включая шаги погрузки/разгрузки. Анимация не расходует дополнительный заряд. Запас всегда виден под полем. Последняя доставка на последнем заряде засчитывается. Перезапуск бесплатный.

**Заказ по номерам** вводится на 22-м участке. В верхнем задании и около платформ указаны номера, следующая станция подсвечена. Станция вне очереди пропускает вагон дальше и показывает причину «Сначала №…». Для одинаковых цветов номер тоже важен.

Настройки во время рейса заблокированы. Доступны пауза, один шаг, скорость ×2 и бесплатный возврат к подготовке. Пробел — запуск/пауза, стрелка вправо — шаг, R — возврат. На телефоне настройки под полем; кнопки на поле тоже работают.

## Сохранения
Ключ `sdvig-dispatch-v25` сохранён. Данные и решения участков 1–5 не менялись: планы, отметки прохождения и текущий участок сохраняются. Новые номера добавлены в тот же объект. Перенос localStorage между разными браузерами, доменами и путями локальных HTML зависит от браузера; это не облачная синхронизация. Прежние версии проекта сохранены отдельно.

## Проверки и сборка
Проверки правил: `node tools/test-core.cjs`, `node tools/test-campaign.cjs`, `node tools/check-plans.cjs`. В отчётах сохраняются все найденные решения, бюджеты и инженерные показатели сложности. Сравнение первых пяти участков: `node tools/compare-rules.cjs` при наличии соседней папки версии 0.26.

Браузер: `node tools/test-browser.cjs`, `node tools/test-campaign-ui.cjs`, `node tools/test-polish.cjs`, `node tools/test-anchors.cjs`. Нужны Playwright, Chromium `/usr/bin/chromium` и сервер 8127. Проверка встроенного HTML: `node tools/test-offline.cjs`, файл сборки должен раздаваться сервером 8128.

`python tools/build.py` создаёт автономный HTML, ZIP игры, обычную сборку и исходники в `dist/`; `SDVIG_OUT` меняет папку вывода. `node tools/design-campaign.cjs` воспроизводит статические данные 25 уровней и выбирает самое короткое найденное решение среди всех допустимых программ.

Готовые WebP включены. Исходный атлас новых индикаторов — `art-source/campaign-atlas.png`; `python tools/extract-campaign-art.py` нарезает целые объекты по прозрачности, включая края и тени, без соседних фрагментов. Только для повторной нарезки нужны Pillow, NumPy и SciPy. Для запуска игры эти зависимости не нужны.

## Ограничения
Это кампания из 25 участков на подготовленных путях. Свободного строительства рельсов, нескольких поездов, музыки и звука пока нет. Проверен Chromium, включая эмуляцию touch; физические телефоны и Safari не проверены. Автоматический запуск file:// блокируется политикой управляемого Chromium: отсутствие внешних запросов проверяется через автономный HTML после отключения сети. Оценка сложности по числу программ и операций не заменяет тестирование интересности с игроками.
