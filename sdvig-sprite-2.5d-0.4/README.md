# Склад 2.5D — проба 0.4

Убраны отдельные напольные стойки крана. Теперь два продольных пути подвешены к потолку, короткий двухбалочный мост ездит вдоль склада по X, тележка перемещается по мосту в глубину по Z. Крюк поднимается отдельно. Рисованный фронтальный вид, быстрый отклик, физический подвес, столкновения и мягкие тени сохранены.

## Попробовать

Распакуйте ZIP и откройте Sdvig_SPRITE_25D.html. Интернет не нужен. WASD — по площадке, Q/E — поднять/опустить, пробел — сцепка, R — заново, P — пауза. Мышью кран не телепортируется.

На телефоне первый палец перемещает кран, второй палец вверх/вниз управляет высотой. Кнопка сцепки работает при удерживаемом пальце. После сворачивания — «Продолжить». Для обзора лучше горизонтальная ориентация. Чтобы пройти дальше влево на телефоне, можно несколько раз провести пальцем влево, поднимая его между жестами.

Для наглядности слева уже открыт пустой проверочный пролёт: продолжайте ехать влево, камера плавно последует за мостом. Здесь можно опустить груз на настоящий физический пол. Два ряда и 12 размеченных мест по всему тестовому складу; дополнительные ящики не создаются. Это проверка конструкции и прокрутки, а не покупка расширения за деньги.

## Подготовка расширения

Границы склада HALL в src/physics.js задают пол, стены-ограничители, диапазон движения крана, видимые пути и пределы камеры. Текущий диапазон X от -16.8 до 6.8 м; проезд крана с отступами от стен от -15.7 до 5.7 м. Разметка BAYS задаётся отдельно. Для будущего расширения не требуется переделывать геометрию моста: он всегда перекрывает глубину склада. Механизм покупки площади и перестройки во время игры пока не реализован.

Фон — повторяемая рисованная панорама, без замыкающей стены слева. Соседние фрагменты зеркалятся для стыка. При прокрутке фон, пол, разметка, грузы, тени и кран смещаются вместе. Обратная проекция жеста учитывает смещение камеры, чтобы управление продолжало работать в новом пролёте. Камера имеет свободную центральную зону и следует за мостом у её границ.

## Что сохранено

Canvas 2D, PNG-спрайты, без расчёта света и карт теней. Мягкие тени под ящиками — один кэшированный рисунок, меняющий размер и прозрачность по высоте. Cannon-es 0.20.0, объёмные коробки с фиксированной ориентацией, гравитация 9.81 м/с², шаг 120 Гц, односторонние трос и стропы. Массы: крюк 45 кг, поддон 420 кг, ящики 680 кг. Отклик крана и ограничения скорости из 0.3.1 сохранены. Предыдущие сборки и бизнес-сохранения не меняются.

## Проверки и ограничения

reports/browser.json — клавиатура, укладка обычными командами, реальные двухпальцевые события Chromium, сцепка с удерживаемым пальцем, пауза, горизонтальный/вертикальный экран. reports/scroll.json — перенос исходного груза влево, сопровождение камерой, укладка на пол нового пролёта без телепортации, возврат вправо и реальный жест после прокрутки. reports/physics.json — падение, укладка, ослабление подвеса, повторная сцепка и подъём, отдельность рядов; изолированные физические сценарии частично используют заданные начальные позиции. reports/response.json — короткий отклик управления и проекция. reports/offline.json — standalone HTML с отключённой сетью при подаче единственного HTML из памяти; file:// в автоматизации не проверен из-за политики Chromium среды.

Это отдельная проба: без экономики, заказов, грузовика, рабочего, сохранения, звука и покупки расширения. Четыре нарисованные ветви строп используют одно физическое соединение, без симуляции каждой нити. Грузы и крюк не вращаются по договорённости. Фон повторяется, сложная сортировка частично пересекающихся спрайтов не гарантирована. Камера движется только по горизонтали. Прототип проверен в браузере среды, реальные телефоны ещё требуют пользовательской проверки. Canvas под разрешение экрана с DPR до 2; текстуры имеют конечное разрешение.

## Исходники

src/physics.js — физика и размеры склада; src/main.js — управление, камера и подвесной кран; src/projection.js — фронтальная проекция; src/contact-shadows.js — мягкие тени; src/touch-controls.js — роли пальцев. assets/ — рисунки, vendor/ — Cannon-es и MIT-лицензия.

Пересборка: Node.js, npm install, npm run build. Упаковка — python tools/package.py. Физические проверки — npm test. Браузерные сценарии требуют Playwright, Chromium и сервер всего репозитория на порту 8160. Готовый HTML зависимостей не требует.
