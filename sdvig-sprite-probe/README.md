# Рисованная проба склада

Откройте Sdvig_SPRITE_PROBE.html в браузере. Интернет не нужен. Это отдельная короткая проба графики и физики, не замена полной игры 0.47; старые сохранения не изменяет.

A/D или стрелки — движение крана; Q/E — подъём/опускание; пробел — отцепить/подцепить поблизости; R — заново. На сенсорном экране ведите пальцем по сцене: горизонтально — кран, вертикально — подвес. Кнопки подъёма и сцепки также работают.

Цель: доставить поддон на правую отмеченную площадку. Деревянный ящик — физическое препятствие, его можно толкать грузом. Поддон может упасть и перевернуться.

Рисованный фон и четыре PNG-спрайта, Canvas 2D, Matter.js 0.20.0 (MIT). Никаких расчётов освещения и теней. Физика в одной вертикальной плоскости, фиксированный шаг 120 Гц, кадры requestAnimationFrame, canvas под реальный экран с DPR до 2. У исходной графики конечное разрешение 1672×941, не бесконечное масштабирование. На больших 4K экранах рисунок не получит новых деталей.

Ограничения образца: ракурс изменён на боковой для проверки физики; это не точная копия изометрического концепта. Нет движения в глубину, торговли, машины, рабочего, сохранений, аудио или полноценного игрового цикла. Одна физическая форма поддона, стропы рисуются линиями и управляются одним физическим соединением. Эти ограничения сознательно оставлены для короткой проверяемой пробы.

Исходники: index.html, game.js, assets/, vendor/. Сборка standalone: python tools/package.py. Изображения подготовлены генератором изображений, не скриншот старой 3D-версии.

Проверки: автоматизированно проверены раскачивание при разгоне, контакт груза с ящиком, падение на пол, клавиатура, кнопки, размеры экрана 1600×900 / 1920×1080 / 390×844 / 844×390. Standalone HTML проверен при отключённой сети с подачей единственного HTML из памяти; прямой file:// в Chromium тестовой среды запрещён политикой и не проверен. Подробности test-results.json и offline-results.json. Скорость на вашем устройстве ещё не измерена.
