# Сдвиг 0.13 — тест всех 500 уровней

Готовая автономная HTML-версия игры «Сдвиг — Хранители маяков». Все 500 уровней открыты для тестирования. Графика и игровые данные встроены, дополнительные файлы не нужны.

## Скачать игру

- [Скачать ZIP](https://github.com/Pash1n/gptgame/raw/refs/heads/main/Sdvig_0.13_TEST_ALL_500.zip) — распакуйте, затем откройте `Sdvig_TEST_ALL_500.html` в браузере.
- [Скачать HTML](https://github.com/Pash1n/gptgame/raw/refs/heads/main/Sdvig_0.13_TEST_ALL_500.html) — сохраните файл с расширением `.html` и откройте в браузере. Если браузер показывает код, скачайте ZIP выше.

Выбор уровня: **Карта → номер уровня внизу → Открыть**. Сохранение тестовой версии отделено от основной кампании.

## Проверено

Все 500 уровней автоматически пройдены в Chromium. Для уровней 21–500 после каждого хода сравнивались игровой и расчётный движки. Проверены клавиатура, жесты, отмена, восстановление сохранения и мобильные размеры экрана. В автономной HTML-версии проверено отсутствие запросов за внешней графикой, включая карту.

Физические смартфоны, Safari и Firefox не проверены. Полноценный плейтест людьми ещё нужен. Прямое открытие file:// запрещено политикой тестовой облачной среды, поэтому автоматические проверки выполнялись через HTTP.
