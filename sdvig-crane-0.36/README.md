# Магнитная мастерская 0.36 — свалка → верстак → редуктор

Первый законченный цикл новой игры: добыть шесть деталей на физической свалке, собрать редуктор на отдельном трёхмерном верстаке, затянуть четыре болта и запустить передачу. Это один узел будущей станции, не готовая кампания строительства города.

Распакуйте игровой ZIP и откройте `Sdvig_MAGNETIC_CRANE.html`. Все модели, материалы, фон и код находятся внутри HTML. Установка и интернет не нужны, требуется WebGL. Основной ZIP меньше 100 МБ.

## Играть

Новый уровень выбран при первом запуске. Нужны корпус, два вала, две шестерни и крышка: все идут в голубой приёмник справа. Оранжевый принимает обычный лом. На площадке 30 настоящих физических предметов, включая шесть целевых.

ПК: WASD — перемещение, Q/E — вверх/вниз, пробел — магнит, P — пауза. Телефон: первый палец перемещает, второй меняет высоту, большая кнопка включает магнит. Верхние восемь ламп магнита загораются красным при включении.

После доставки деталей откройте «Верстак». Перетаскивайте текущую деталь в её подсвеченное посадочное место. Положение доводится мягко, без таймера. Затем удерживайте каждый из четырёх подсвеченных болтов около секунды. Запустите механизм, откройте крышку на петлях и рассмотрите вращение шестерён. Кнопка «Разобрать заново» повторяет сборку из уже добытых деталей.

**Сразу попробовать сборку:** меню → «Тест верстака · детали выданы». Выданные детали и пробная сборка не меняют основной прогресс. В исходной веб-версии также доступен `?workbench=1`.

## Сохранения и прежняя игра

Сохранён ключ `sdvig-crane-v1`, старые `completed`, `storyCompleted`, `storyCurrent`, `graphicsMode` не обнуляются. Добавлены `stationParts` (доставленные детали) и `gearboxAssembly` (установленные детали, затяжка каждого болта). Частичная добыча и сборка сохраняются; точное положение кучи — нет. LocalStorage привязан к браузеру и адресу файла/сайта: перенос файла или другой браузер не гарантируют перенос сохранения.

Прежние десять глав перевозчика, три заказа и свободная игра доступны через меню. Тестовый доступ ко всем прежним главам сохранён. Никакие файлы 0.35 и более ранних версий не удалены.

## Разработка

```sh
npm ci
npm run build
node tools/test-requisition.mjs
node tools/test-assembly-browser.cjs
node tools/test-workshop-regressions.cjs
python3 tools/package.py
```

Браузерные тесты используют Playwright и Chromium (`/usr/bin/chromium`), исходная версия обслуживается на порту 8144. После первого успешного физического прохождения `ASSEMBLY_ONLY=1 node tools/test-assembly-browser.cjs` повторно проверяет интерфейс с инвентарём, заработанным этим прохождением. Это явная тестовая подготовка, не дополнительное прохождение свалки. Офлайн-тест проверяет упакованный HTML на порту 8137.

Унаследованные инструменты 0.35 сохранены для справки; часть их URL и ожиданий относится к прежнему стартовому экрану. Фактически выполненные проверки этой версии перечислены в `REPORT_RU.md`, результаты в `reports/`.
