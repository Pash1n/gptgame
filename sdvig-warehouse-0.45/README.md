# Сдвиг · Груз и подвеска 0.45

Принятый груз сохраняет физические столкновения; кузов, борта, разметка и груз следуют пружинной подвеске. Колёса остаются на земле. Чёткое качество по умолчанию и сохранение ручного выбора. Рессоры, протектор, оси и детали платформы.

[Запуск и управление](README_RU.md). `npm test`, `node tools/test-truck.mjs`, `node tools/test-truck-browser.cjs` (сервер 8156, Chromium/Playwright).
