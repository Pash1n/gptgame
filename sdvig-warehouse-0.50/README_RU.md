СДВИГ 0.50 — ЖИВАЯ КОМПЛЕКТАЦИЯ

Распакуйте ZIP и откройте Sdvig_WAREHOUSE.html в современном браузере с WebGL2. Изображения, JS и Jolt WASM встроены, постоянный интернет не нужен. Проверка в управляемом Chromium проведена по HTTP с последующим отключением сети; file:// запрещён политикой этой среды и здесь не проверен.

ПЕРВЫЙ ЗАКАЗ
1. Компьютер → «Заявки» → изучите состав → «Закупить недостающее». Подтвердите закупку у поставщика.
2. Разгрузите транспортные ящики краном на жёлтые места. Поднимите крюк после отцепления: складской стропальщик снимет обвязку. Дождитесь отъезда поставщика.
3. В компьютере у заявки нажмите «Начать сборку». На бирюзовой площадке у стола появится настоящий открытый пустой ящик клиента.
4. Закройте компьютер, нажмите «Сборка». Выберите строку спецификации. Подсветятся подходящие складские источники. Можно нажать источник в зале или выбрать его карточку в панели. Укажите количество и нажмите «Принести».
5. Комплектовщик сам дойдёт до источника, возьмёт коробку и отнесёт в ящик клиента. Источники к столу подвозить НЕ НУЖНО. Счётчик заказа меняется после укладки. Пока работник носит товар, можно добавить другие позиции и источники в очередь.
6. Полный ящик или полностью собранный заказ закрывается автоматически. Неполный ящик можно закрыть вручную кнопкой «Закрыть ящик» после завершения переносов. 25 — максимальная вместимость, не обязательное заполнение.
7. Если заказ ещё не собран, уберите закрытый ящик краном на свободное место склада или бирюзовое место буфера отгрузки справа от стола. Затем «Поставить пустой ящик» и продолжайте сборку.
8. Можно вернуть закрытый неполный ящик на сборочную площадку, отцепить, поднять крюк и дать снять стропы. Нажмите «Открыть и продолжить» — содержимое сохранится. Дополнение не оплачивается второй раз. Если у стола уже стоит другой пустой ящик, «Убрать пустой ящик» вернёт его упаковочные 20 ₽.
9. Весь состав разложен по закрытым ящикам: компьютер → текущая заявка → «Вызвать машину». Погрузите ВСЕ ящики этого заказа. Они маркируются номером заказа и собственным номером ящика, например «Заказ №2 · ящик 1».
10. После крепления всех ящиков компьютер → «Отправить заказ». Оплата приходит после выезда. До команды отправки машина ждёт.

ДВА КОМПЛЕКТОВЩИКА
Компьютер → «Развитие» → «Второй комплектовщик» → «Нанять за 1 500 ₽». Это разовая покупка, ежесменной зарплаты пока нет. Двое работают с общей очередью, каждый получает собственное задание. Взятые коробки сохраняются даже при перезагрузке с товаром в руках.

НЕСКОЛЬКО ЯЩИКОВ
В начале машина принимает до двух погрузочных мест. После транспортного улучшения — до четырёх. Заявка на 32 коробки сразу доступна для пробы, но сначала нужно закупить её состав. После улучшения есть заявка на 70 коробок. Можно закрывать ящики раньше заполнения, но все места заказа должны поместиться в доступную машину. Если заняли все места неполными ящиками — верните один и дополните, вместо создания ещё одного.
В компьютере показан минимальный расчёт мест, фактическое число зависит от заполнения. Буфер отгрузки — три бирюзовых прямоугольника перед зоной погрузки; последний ящик можно оставить у стола. Они не увеличивают количество мест для закупаемого сырья. Есть также четыре места склада и расширение до восьми.

ОЧЕРЕДЬ И БЕЗОПАСНОСТЬ
«Убрать очередь» отменяет ещё не взятые коробки. То, что уже в руках, работник донесёт. Нельзя закрыть ящик во время переносов, подцепить открытый ящик или перемещать обслуживаемый источник. Чтобы снять стропы вручную, выберите груз и нажмите «Снять стропы».
Пустые исходные ящики после последнего переноса убираются автоматически, освобождая место. Отмены всего уже заполненного заказа и возврата его содержимого в источники в 0.50 пока нет.

УПРАВЛЕНИЕ
ПК: WASD — перемещение крана по полу; Q/E — крюк вверх/вниз; пробел — отцепление поставленного груза. Мышь выбирает груз/источник и кнопки; щелчок по полу не перемещает кран. Колесо мыши — масштаб, P — пауза.
Телефон: один палец перемещает кран; второй палец вверх/вниз меняет высоту. Короткое касание груза вызывает стропальщика; с открытой сборкой касание подходящего источника выбирает его. Кнопки «Отцепить» и «Снять стропы» внизу. Панель сборки можно закрыть крестиком и продолжать наблюдение.

СОХРАНЕНИЯ
0.50 использует отдельный ключ sdvig-metiz-assembly-v2. При первом запуске в том же браузере/источнике читает сохранение 0.49 из sdvig-metiz-business-v1, но не перезаписывает его. Деньги, товар, расширение и старый уже закрытый заказ сохраняются. Незакрытая ручная сборка 0.49 возвращается в исходные ящики; затем нужно убрать их со сборочной площадки и поставить новый пустой. Если браузер хранит каждый локальный HTML в отдельном хранилище, автоматический перенос между файлами может быть недоступен.

ОГРАНИЧЕНИЯ ПРОТОТИПА
Одна заявка и один открытый ящик одновременно. Максимум два комплектовщика; каждый носит по одной коробке. Только 30 товарных позиций. Масса транспортного ящика пока фиксированная. Маршруты работников обходят груз, стол и автомобиль, но нет физики человеческих тел и точного захвата пальцами. Цены и заказы игровые, спрос циклический; зарплаты, аренда и следующие расширения пока не сделаны. Работу и скорость на настоящем телефоне нужно проверять отдельно.

ИСХОДНИКИ И ПРОВЕРКИ
npm ci; npm run build. npm test запускает проверку реальных физических переносов, сборки и отгрузки; дополнительно node tools/test-assembly-guards.mjs. Браузер: python -m http.server 8162 и node tools/test-assembly-browser.cjs (нужны Playwright и Chromium). Упаковка: python tools/package.py. Подробный отчёт: REPORT_0.50_RU.md. Старые scripts test-metiz и reports/legacy049 оставлены для истории 0.49; актуальные проверки — assembly.
