# Сдвиг 0.50 — живая комплектация

Работники носят коробки от складских источников. Один заказ собирается в несколько физических ящиков, неполный можно закрыть, убрать, вернуть и дополнить. В компьютере — ручной вызов машины, отправка и найм второго комплектовщика.

Запуск и управление: [README_RU.md](README_RU.md). Выполненные проверки и ограничения: [REPORT_0.50_RU.md](REPORT_0.50_RU.md).

`npm ci`, `npm run build`, `npm test`. Проверки с Jolt выполняют физические действия краном без телепортации грузов. Браузерные проверки используют сервер 8162 и установленный Playwright/Chromium. `python tools/package.py` создаёт автономный HTML и ZIP до 100 МБ каждый.
